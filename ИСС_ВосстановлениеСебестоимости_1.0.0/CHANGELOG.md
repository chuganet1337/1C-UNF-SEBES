# История изменений

## 1.0.0 — 09.09.2026

- Удален опасный сценарий частичной цепочки по одной номенклатуре.
- Добавлено формирование плана без изменения данных.
- В план включаются все проведенные документы периода.
- Добавлена сортировка по `МоментВремени`.
- Добавлено неоперативное проведение пакетами по 10 документов.
- Добавлена остановка после текущего пакета.
- Добавлена остановка на первой ошибке.
- Добавлена блокировка запуска при неполном плане.
- Добавлено обязательное подтверждение резервной копии.
- Добавлено журналирование плана, документов, ошибок и результата.
- Добавлен быстрый контроль сводного состояния регистра `Запасы`.
- Добавлено явное требование повторного закрытия месяцев.
