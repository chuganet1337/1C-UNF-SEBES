# ИСС: Восстановление себестоимости УНФ

Версия: **1.0.0**

Назначение: контролируемое повторное проведение документов выбранного периода для восстановления последовательности учета перед повторным закрытием месяца.

## Главное отличие от EPF v5

В расширении нет исправления «одной номенклатуры». В план включаются **все проведенные документы выбранного периода**. Это исключает незамкнутую цепочку, когда многострочный документ изменяет движения связанных товаров, а последующие документы по ним не перепроводятся.

## Сценарий работы

1. Оператор выбирает период.
2. Команда «Сформировать план» только читает данные, собирает все проведенные документы и сортирует их по платформенному `МоментВремени`.
3. Если хотя бы один вид документов не удалось прочитать, запуск блокируется.
4. Перед запуском необходимо подтвердить наличие проверенной резервной копии.
5. Документы перепроводятся неоперативно пакетами по 10, строго в порядке плана.
6. При первой ошибке операция останавливается. Ранее успешно проведенные документы не откатываются; ошибка и документ фиксируются в журнале регистрации.
7. После успешного выполнения необходимо выполнить типовое закрытие месяцев по порядку — от самого раннего измененного месяца к последнему.
8. Команда «Быстрый контроль» проверяет сводные остатки регистра `Запасы`. Окончательный контроль выполняется типовыми отчетами УНФ.

## Безопасность

- Запускать сначала только на тестовой копии базы.
- До рабочего запуска создать и проверить резервную копию.
- На время выполнения вывести пользователей, остановить обмены и фоновые задания.
- Учитывать запрет изменения данных и закрытые периоды.
- Выполнять под пользователем с полными административными правами.
- Не считать операцию законченной до повторного закрытия месяцев и проверки типовых отчетов.

Расширение не удаляет данные, не выполняет сетевые вызовы и не запускает внешние программы. Оно изменяет учетные движения посредством штатного повторного проведения объектов документов.

## Состав

- `Configuration.xml` — описание расширения версии 1.0.0;
- `CommonCommands` — команда открытия рабочего места;
- `Subsystems` — отдельный раздел интерфейса;
- `DataProcessors` — форма, планировщик, пакетное выполнение и быстрый контроль;
- `ConfigDumpInfo.xml` — служебное описание XML-выгрузки.

## Сборка

Каталог является XML-выгрузкой расширения для Конфигуратора 1С. Его следует загрузить в расширение с именем `ИСС_ВосстановлениеСебестоимости`, проверить применимость к целевой УНФ, обновить конфигурацию расширения и выгрузить в файл `.cfe`.

Бинарный `.cfe` должен собираться той версией платформы, на которой работает целевая база. После получения точного релиза УНФ и доступа к Конфигуратору необходимо выполнить:

1. загрузку исходников в тестовую базу;
2. проверку синтаксиса модулей;
3. проверку применимости расширения;
4. формирование плана на коротком тестовом периоде;
5. контрольный прогон и повторное закрытие месяца;
6. выгрузку проверенного `.cfe`.

## Ограничения версии 1.0.0

- Автоматическое закрытие месяца не вызывается: внутренние интерфейсы этой процедуры зависят от релиза УНФ.
- Запрет изменения данных и остановка фоновых заданий не снимаются автоматически.
- Возобновление после ошибки выполняется новым планом после устранения причины.
- Быстрый контроль агрегирует остатки по номенклатуре и не заменяет анализ по складам, партиям, характеристикам и организациям.
- XML-исходники сформированы без целевой конфигурации и требуют проверки Конфигуратором перед применением.
